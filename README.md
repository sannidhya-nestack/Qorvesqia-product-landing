# Qorvesqia AI — Live Event Production Operating System

**Industry:** Entertainment  
**Sub-industry:** Event Production & Live Entertainment  
**Product ID (`insubId`):** `insub_ENT043`  
**Live Target:** `https://qorvesqia.nestack.ai`  

## Executive Overview
Qorvesqia AI is an AI-native operations operating system purpose-built for organizations responsible for planning, producing, technically delivering, operating, and financially settling professional live events, arena tours, and multi-stage music festivals.

## Core Operational Modules
1. **Dashboard:** Production Command Center with Readiness Index, Run-of-Show Pulse, and AI Risk Queue.
2. **Event Intake:** Automated artist rider OCR extraction, technical venue spec audits, and instant bill-of-quantities.
3. **Production Planning:** Master production timeline scheduling, load-in milestones, and downstream change ripple analysis.
4. **Technical Production:** Coordinated audio splits, DMX universes, LED video tile rasters, and stage rigging point load audits.
5. **Crew & Resources:** Intelligent crew scheduling, digital call sheets, and IATSE union overtime / meal penalty guardrails.
6. **Vendors & Logistics:** Loading dock scheduling, freight tracking, and cross-vendor load-in conflict detection.
7. **Show Operations:** Synchronized digital cue calling, live run-of-show execution, timecode tracking, and curfew delay mitigation.
8. **Safety & Compliance:** ANSI E1.21 wind action thresholds, ANSI E1.6 hoist safety, NFPA 101 crowd safety, and AHJ inspection sign-offs.
9. **Settlement & Closeout:** Real-time labor overtime reconciliation, rental gear reconciliations, and automated promoter settlement exports.

## Tech Stack
- **Framework:** Next.js 16 (App Router) + React 19 + TypeScript
- **Styling:** Tailwind CSS v4 + `tw-animate-css`
- **Shell Architecture:** Pure vector SVG dashboard shell composite with cropped content plates
- **Shared API Integration:** Nestack Platform API for dynamic pricing, demo calendar slots, and lead intake.
